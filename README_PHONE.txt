INVESTWISE PHONE EDITION (PWA-ready)

Files:
- index.html: the app
- manifest.webmanifest: install metadata
- sw.js: offline caching
- icons/: app icons

IMPORTANT:
This package must be hosted on an HTTPS website before Android Chrome can offer proper PWA installation.
The app stores records in browser localStorage on the device/browser profile. It does not sync to a laptop or cloud.
There are no live market feeds, broker connections or trading functions.

Suggested free publishing route:
1. Sign in/create an account at github.com.
2. Create a public repository named investwise.
3. Upload all files and the icons folder from this ZIP to the repository root (not the ZIP itself).
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published GitHub Pages address.
6. Open that HTTPS address in Chrome on Android. Use Chrome menu > Add to Home screen or Install app if offered.

Keep the repository public if using free GitHub Pages. Do not upload private financial information or credentials.
